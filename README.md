# QuickBooks Online Cleanup Checklist

The step-by-step checklist I use to clean up and catch up QuickBooks Online files that are months, or years, behind. It works for any small business, with extra steps for real estate investors.

Work through it in order and you'll end with books that reconcile to the bank and are ready for your CPA.

## 1. Gather what you need

- [ ] Admin or accountant access to QuickBooks Online
- [ ] Bank, credit card and loan statements for every month in the cleanup period
- [ ] Last filed tax return and the CPA's year-end adjusting entries
- [ ] Loan amortization schedules, plus closing statements for any property bought or sold
- [ ] Payroll reports, if payroll runs outside QuickBooks
- [ ] A list of every bank, credit card, loan, PayPal and Stripe account the business uses

## 2. Assess the file before changing anything

- [ ] Note the last reconciled month for every account (Reconcile page → History by account)
- [ ] Run the Balance Sheet and Profit and Loss for each year in scope
- [ ] Check the balances in Uncategorized Income, Uncategorized Expense, Ask My Accountant and Undeposited Funds
- [ ] Count the transactions waiting for review in Bank transactions
- [ ] Run A/R Aging and A/P Aging and note old open items
- [ ] Check whether prior years are closed and still match the filed tax return
- [ ] Agree on scope, timeline and price with the client before starting

## 3. Fix the setup

- [ ] Clean up the chart of accounts: merge duplicates, make unused accounts inactive
- [ ] Turn on classes or locations and create one per property or department
- [ ] Review bank rules and delete the ones that miscategorize
- [ ] Confirm opening balances match the first statement in scope

## 4. Clean up transactions

- [ ] Match bank feed items to existing invoices, bills and payments before adding new ones
- [ ] Categorize every transaction to the correct account and class
- [ ] Find and remove duplicates (bank feed imports plus manual entries)
- [ ] Clear Undeposited Funds by grouping payments into the real bank deposits
- [ ] Record transfers between accounts as transfers, not as income or expense
- [ ] Split loan payments into principal, interest and escrow
- [ ] Clear Uncategorized and Ask My Accountant to $0, asking the client about anything unclear
- [ ] Close out old invoices and bills that were already paid or should be written off

## 5. Reconcile every account

- [ ] Reconcile each bank, credit card, loan and payment processor account month by month
- [ ] Get every reconciliation to a $0 difference
- [ ] Investigate any change to an already reconciled transaction before moving on
- [ ] Save the reconciliation report for every month

## 6. Review

- [ ] Every balance sheet account ties to a statement or a schedule
- [ ] Loan balances match the lender's statements
- [ ] Fixed assets and accumulated depreciation match the CPA's depreciation schedule
- [ ] Equity makes sense: contributions, distributions, retained earnings
- [ ] Profit and Loss by Class shows each property correctly
- [ ] Nothing is left in Uncategorized, Ask My Accountant or Undeposited Funds

## 7. Deliver

- [ ] Profit and Loss, Balance Sheet and Statement of Cash Flows for the period
- [ ] Reconciliation reports for every account
- [ ] A log of every change made during the cleanup
- [ ] A closing date, with a password, so reconciled periods stay locked
- [ ] A plan for monthly bookkeeping so the file doesn't fall behind again
